# WhatsApp messages: cafés and creators (EN + KN drafts)

Pricing: ₹20 per counted customer, first 3 each month free, never more than ₹399 a month. Creators are always free.

**Before using these drafts:**
- **Meta templates.** Any message Mitra starts outside the 24-hour window must be an approved WhatsApp template. The evening summary, bill notice and receipt are **utility**. Messages offering Pro or inviting a café are **marketing**, which costs more and needs opt-in.
- **Kannada review.** The Kannada is a draft. Have a native speaker in Bengaluru read it before you submit the templates.
- **Variables.** Text in {braces} is filled in per message.

## Rules these messages follow
- **No fake proof.** Every number is real data for that café or creator. The "23 customers" in message 11 must be shown as an example, or the sentence reworded, so it isn't read as a claim.
- **The official number states once** what Mitra will never ask for (bank details, OTP, card number).
- **No auto-debit.** Every charge is announced 3 days ahead and can be disputed. STOP works in every message.
- **ASCI:** a creator's post with a Mitra coupon is a paid or barter collab, so the creator must disclose it (#collab / #ad). Add that to the creator's coupon screen.
- **Not legal advice.** Confirm consent wording and template categories with Meta's current WhatsApp policy.
