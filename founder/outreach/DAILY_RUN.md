# Mitra daily outreach run (what the scheduled task does)

Tracker: https://claude.ai/artifact/Qkm2htneaa3383hm2KWthy (collection `contacts`, docs `meta/plans`, `meta/runs`)
Mailbox: mitracontentsupport@gmail.com (drafts only; a person reads and sends every email)

## Each run
0. Check the connected Gmail is mitracontentsupport@gmail.com. If not, write `meta/runs` "blocked: wrong mailbox", create nothing, stop.
1. Replies: find replies from contacted addresses; set status replied / answered / declined / stop, put the reply (short) and the three answers on the row, label the thread "Mitra Outreach". "Stop", "unsubscribe", "not interested, don't email" = status stop, forever.
2. Follow-ups: rows `sent` 5+ days ago with no reply and no follow-up yet → one two-line follow-up draft in the same thread. Never a second.
3. New contacts (skip anyone already in the tracker or stopped):
   - 10 creators: Kannada (or Kannada + English) creators on Instagram/YouTube, roughly 5K–200K followers, with a business email they published themselves (bio, YouTube About text shown in search results, website, link-in-bio).
   - 10 business side: Bengaluru local businesses (cafes, restaurants, salons, gyms, coaching centres, clinics), Karnataka/South India D2C brands, influencer agencies and creator managers, affiliate programs. Business email from their own website.
   - Up to 5 Instagram DM rows (public accounts with no email): channel `instagram`, status `queued`, DM text ready to paste. A person sends these by hand.
   Never guess or construct an email address. Never scrape behind logins. Record the source link.
4. Draft the emails in Gmail (do not send) and write the rows (status `drafted`).
5. When 10 creators and 10 business-side contacts are `answered` and `meta/plans` has no rating yet: rate the plans (below) from the answers and write `meta/plans`.
6. Write `meta/runs` (date, drafted, replies, answers so far, anything blocked).
