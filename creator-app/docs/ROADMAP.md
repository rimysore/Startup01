# Mitra roadmap

Agreed build order (October 2026). Retention first: value that compounds, never dark patterns
(India's CCPA dark-pattern guidelines ban subscription traps, confirm-shaming, nagging).

## Next up, in order
1. **Monday report (WhatsApp, email fallback) + 48-hour post-upload check** — 3 wins, 3 fixes, what to post.
2. **Monthly "Mitra receipt"** — track which suggestions were used and how those videos did vs the
   channel's own average; hours saved.
3. **Pause subscription (₹49/mo keeps history), annual plan (2 months free), exit survey with one offer.**
4. **Media kit + rate card** — first step of "grow with them" (10K–1L creators need income, not tips).
5. **Churn-risk list on the admin page** — no login 14d, no upload 21d, credits unused, YouTube
   disconnected, payment failed; founder messages them personally.

## Later
- Speech-to-text pre-publish check (Sarvam, ~₹30/hour of audio), transcript-aligned retention.
- Brand deals: deal tracker → collab matchmaking → brand marketplace (see docs/BRAND_DEALS.md).
- Creator prospecting pipeline for outreach (see docs/PROSPECTING.md), automated later.
- Personal playbook / long-term memory per channel; Instagram; team seats.
